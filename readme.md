# 🚗 Car Price Prediction

A simple Machine Learning project that predicts the price of a car using Streamlit.

## Features

- Car Price Prediction
- Machine Learning
- Random Forest Regression
- Streamlit Web App
- CSV Dataset

## Dataset

The dataset contains:

- Levy
- Manufacturer
- Model
- Production Year
- Category
- Leather Interior
- Fuel Type
- Engine Volume
- Mileage
- Price

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
````

Run the Streamlit application:

```bash
streamlit run app.py
```

## Project Files

* `app.py` – Streamlit application
* `car_price.csv` – Car dataset
* `requirements.txt` – Required Python libraries
* `README.md` – Project information
